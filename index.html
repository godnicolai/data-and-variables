Types of Data and Variables in Statistics

A clear, interactive study guide for data analysis and statistics coursework.

Prepared by: Nicolai Talosig

1. Qualitative vs. Quantitative Data

Qualitative (Categorical) Data

Describes qualities, categories, or characteristics. It cannot be measured numerically.

  • Examples: Hair color, marital status, nationality, blood type.
  • Analysis: Count frequencies, percentages, mode.

Quantitative (Numerical) Data

Represents counts or numerical measurements. Mathematical operations can be performed.

  • Examples: Height, weight, temperature, salary, age.
  • Analysis: Mean, median, standard deviation, regression.

2. Discrete vs. Continuous Variables

Discrete Variables

Values that can be counted and have distinct, separate values (usually whole numbers).

  • Number of students in a classroom
  • Number of cars in a parking lot
  • Number of errors in a code file

Continuous Variables

Values that fall on a continuous scale and can take infinitely fine fractions or decimals.

  • Time taken to complete a task (e.g., 4.52 seconds)
  • Height or weight measurements
  • Voltage levels in an electronic circuit

3. Levels of Measurement (NOIR)

Variables are measured using four distinct scales that determine what kind of statistical analysis can be performed:

N

Nominal Scale

Categories with no inherent mathematical order or ranking. Labels only.

Example: Gender, eye color, programming languages (Python, Java, C).

O

Ordinal Scale

Categories that have a logical order or ranking, but exact differences between ranks cannot be measured.

Example: Survey ratings (Poor, Fair, Good, Excellent), academic year levels.

I

Interval Scale

Ordered numerical values with equal intervals, but no true zero point (zero doesn't mean "none").

Example: Temperature in Celsius or Fahrenheit (0°C does not mean absence of heat).

R

Ratio Scale

Ordered numerical values with equal intervals and a true absolute zero point (zero means total absence).

Example: Weight, height, response time in milliseconds, salary ($0 means no income).
