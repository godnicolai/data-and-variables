Types of Data & Variables

A streamlined reference guide to understanding quantitative vs. qualitative data, discrete vs. continuous variables, and the four levels of measurement.

1. Qualitative vs. Quantitative Data

Qualitative (Categorical)

Non-Numeric

Describes characteristics, labels, qualities, or categories. It places observations into groups rather than measuring numerical quantities.

Examples:
  • Eye color (Blue, Brown, Green)
  • Programming Language (Python, Java, C++)
  • Pass / Fail Result

Quantitative (Numerical)

Numeric

Represents measurable numerical quantities. Arithmetic operations like averages, sums, and standard deviations are physically meaningful.

Examples:
  • CPU Clock Speed (e.g., 3.8 GHz)
  • Monthly Salary ($)
  • Number of server requests per minute

2. Discrete vs. Continuous Variables

Discrete Variables

Variables that take on separate, distinct values (typically whole numbers). Values are usually obtained by counting.

Key Rule: No fractional values exist between counts (e.g., you cannot have 2.5 computers).
Continuous Variables

Variables that can take on any real value within a given interval. Values are obtained by measuring with fine precision.

Key Rule: Infinite decimal precision is possible depending on your tool (e.g., 12.42 seconds).
